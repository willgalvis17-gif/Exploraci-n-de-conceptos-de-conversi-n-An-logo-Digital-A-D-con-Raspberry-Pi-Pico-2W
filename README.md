# Exploraci-n-de-conceptos-de-conversi-n-An-logo-Digital-A-D-con-Raspberry-Pi-Pico-2W
Análisis de conversión A/D con Raspberry Pi Pico 2W (RP2350): captura y procesamiento en MATLAB de 10 000 muestras del ADC por nivel de tensión DC, cálculo de media, desviación estándar y comparación con la referencia del multímetro. Laboratorio de Comunicaciones Digitales — UMNG.
